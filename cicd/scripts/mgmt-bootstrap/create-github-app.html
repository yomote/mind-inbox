GitHub App を作成する (settings-mgmt)

mind-inbox の GitHub 設定管理 (mgmt) 層 — cicd/github/terraform/ — の plan/apply 専用 App を作ります。権限は Repository administration (write) と Metadata (read) だけで、webhook は持ちません。各権限の根拠は同じディレクトリの README.md にあります。

送信される manifest (編集しないでください — 変えるときはリポジトリ側で PR):

作成後にやること (この順で)

  1. App の settings ページで App ID を控える
  2. Install App から yomote/mind-inbox (このリポジトリだけ) にインストールする
  3. Generate a private key で pem をダウンロードする (ダウンロード先のパスを次の手順で使う)
  4. cicd/scripts/mgmt-bootstrap/bootstrap.sh を実行する (手順: docs/runbooks/mgmt-layer-apply.md)

⚠️ pem はスクリプトに渡し終えて格納を確認したら削除します (スクリプトが最後に手順を出します)。メール・チャット・クラウドドライブに置かないこと。
