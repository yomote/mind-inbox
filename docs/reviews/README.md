**rubric の導出元となる一次資料**を置く場所。ADR は「判断」、Runbook は「手順」、ここは「**測った結果**」。

- **書き換えない** — 測定日時点の事実として残す。数字が変わったら新しい日付のファイルを足す

- 一過性のセッション記録は対象外 → [debrief](../debrief/journal.md)
