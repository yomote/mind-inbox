## 共通規約

全画面に効く UI 規約（2026-08-11 PO 裁定 / Issue #237）:

- **UI コンポーネント・アイコンは MUI を優先して使う**（`@mui/material` / `@mui/icons-material`）。
  独自実装や別ライブラリを足す前に、まず MUI で賄えないかを確認する。
- **絵文字をアイコンとして使わない**。バッジ等の視覚マーカーは `@mui/icons-material` の
  アイコン（Chip の `icon` prop 等）で表現する。タイポグラフィ表現
  （ストリーミングキャレット `▍` 等）はアイコンではないので対象外。
